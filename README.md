# merge-short-
LeetCode 21 – Merge Two Sorted Lists

Problem

Merge two sorted linked lists into one sorted linked list.

Language

C

Concepts Learned

- Linked Lists
- Structures
- Pointers
- Traversing linked lists
- Comparing node values
- Time and Space Complexity

Approach

Compare the current nodes of both linked lists and attach the smaller node to the result. Continue until one list becomes empty, then attach the remaining nodes.

Complexity

- Time: O(n + m)
- Space: O(1)

Key Learning

Practiced using pointers to efficiently merge two sorted linked lists without creating a new list.
